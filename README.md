一、安装
1. 双击 Kickstarter追踪器-安装包-1.0.0.exe
2. 如果 Windows 弹出蓝色的「已保护你的电脑」提示：
  - 点左边的「更多信息」
  - 再点「仍要运行」
  - 这是因为安装包没有购买数字签名证书，不是病毒。
3. 选择安装位置（默认即可），点「安装」
4. 安装完成后，桌面和开始菜单都会出现「Kickstarter Tracker」图标
安装过程不需要管理员权限，也不会修改系统设置。
二、第一次打开
双击桌面图标即可。首次启动会花 30～60 秒 做一次网络校验（这是 Kickstarter 的
网站防护机制要求的），期间界面可能显示「正在抓取…」，属正常现象，耐心等一下。
之后启动会快很多。
三、主要功能
1. 添加众筹项目
把 Kickstarter 的项目网址粘贴到输入框，点「添加」。
支持的项目网址形如：
https://www.kickstarter.com/projects/创建者名/项目名
⚠️ 必须具体项目页的网址。首页、分类页、搜索页都不行。
最多可以同时追踪 3 个项目。
2. 浮窗
浮窗是一个小窗口，专门用来随时瞟一眼筹款金额，有三种模式：
      隐藏
      不显示浮窗
      始终置顶

在主界面顶部或右键系统托盘图标都能切换。
浮窗可以直接拖动到屏幕任意位置，位置会自动记住。
